# 语料放这里

把小说存成 `data/novel.txt`（UTF-8 编码）。

## 选哪本书

| 类型 | 例子 | 能不能公开 demo |
|---|---|---|
| **公有领域古典小说（推荐）** | 三国演义、西游记、水浒传、红楼梦、聊斋志异 | ✅ 可以，作者逝世超 50 年 |
| 现代/网络小说 | 任何有版权的作品 | ❌ 只能本地跑，不能上传仓库和公开部署 |

**建议用《三国演义》**：120 回、60 多万字、人物关系复杂、情节人尽皆知 —— 面试官能当场出题验证，这比什么都强。

## 格式要求

- 每章开头单独一行是章节标题，形如：
  - `第一回 宴桃园豪杰三结义 斩黄巾英雄首立功`
  - `第一百二十回 荐杜预老将献新谋 降孙皓三分归一统`
- 章与章之间用空行分隔
- 全文 UTF-8 保存

## 检查规范

```bash
python build_corpus.py
```

如果报"章数 < 10"，说明章节正则没匹配上，检查标题格式（有的版本是"第1回""第001回"，需要调整正则）。

## 版权说明（写进 README）

- 用公有领域作品 → 可以直接写"语料为公有领域文本"
- 用有版权的作品 → 仓库不要提交 `data/novel.txt`（`.gitignore` 已忽略 `data/*`），README 写明"语料需自备"
